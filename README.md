# Food-Waste-Redistribution-System
The Food Waste Redistribution System is a C-based application that helps reduce food wastage by distributing excess food to people or organizations in need. It records food quantity, expiry time, and recipient requirements, then uses simple logical decisions to distribute food efficiently and generate a final report.
